# NW JoyBridge

**NW JoyBridge** is a language assistant app specifically designed for the 2026 "Eternal Happiness" International Convention delegates. The application serves as a communication tool to help attendees and volunteers interact with international delegates by providing quick access to specific language modules. Specifically designed for use in the Service Day activities.

---

## Features

- **Bidirectional Learning & Communication**: View phrases optimized for non-English speakers or English speakers with tailored phonetic pronunciation guides.
- **Text-to-Speech (Audio)**: Instant speech synthesis in supported languages to ensure clear pronunciation and understanding.
- **Offline PWA Readiness**: Operates offline from device cache with progressive web application installation capabilities.
- **Interactive Venue Map & Media**: Direct Google Maps access to the San Diego Convention Center with localized venue guides and preparation media.
- **Dark Mode Support**: Seamless toggle between light and dark themes.
