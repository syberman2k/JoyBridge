NW JoyBridge is a language assistant app specifically designed for the 2026 "Eternal Happiness" International Convention.
The application serves as a communication tool to help attendees and volunteers interact with international delegates by providing quick access to specific language modules.

Available Languages
===================
The app currently features the following language options:
    European Languages: Dutch (Nederlands), German (Deutsch), French (Français), Polish (polski), and Slovenian (Slovenščina).
    Asian & Pacific Languages: Korean (한국어), Tagalog (Filipino), Kannada (ಕನ್ನಡ), Chinese Mandarin (中文), and Konkani written in the Kannada script (ಕೊಂಕಣಿ).
